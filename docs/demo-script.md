# Demo Script

1. Start the app with `bin/rails server`.
2. Open `http://localhost:3000`.
3. Show the dashboard headcount, payroll metrics, and department distribution.
4. Search for an employee by name or employee number.
5. Filter by country, department, level, and status.
6. Sort by salary descending.
7. Select an employee from the table.
8. Update the employee salary with an effective date and reason.
9. Show that the current salary changed and the salary history contains the update.
10. Clear or change filters to show that metrics and pagination respond to the same dataset view.
